# neo — Android · Release 仓库

本仓库是 **neo Android 版的发布仓库**，只放 Release 安装包，不含源码。

## 这是什么

**neo** 是一个基于开源项目的本地代理客户端。需要特别说明的是：

- **内核（核心）是开源项目**：本应用基于 [sing-box-for-android](https://github.com/SagerNet/sing-box-for-android)（SFA）构建，代理内核为 [sing-box](https://github.com/SagerNet/sing-box) **v1.14.2**（libbox，MIT 许可证）。**所有代理协议、传输、加密能力全部来自上述开源项目，neo 没有实现任何私有代理协议。**
- **neo 做的事只有一个：分流路由机制的更改与优化。** 包括但不限于：
  - 针对游戏的分流策略优化（如 PUBG 的 UDP 直连规则注入，避免游戏对局流量经代理转发）
  - 离线真连测速（独立内核会话，不影响 VPN 连接）
  - 界面与交互重制（四屏 UI、连接状态可视化）
  - 自更新通道、签名完整性校验等工程化改进
- 改动均在上游开源许可（MIT）框架内进行，感谢 SagerNet 及 sing-box 社区的上游工作。

## 下载

见右侧 [Releases](https://github.com/lubenwei-lian/neo-release/releases)：下载最新的 `neo-*-arm64-v8a.apk`（主流 64 位 Android 手机），系统内直接安装即可。应用内「设置 → 应用 → 检查更新」可检查新版本。
