# neo — Android

基于开源内核的 Android 本地代理客户端。本仓库只发布安装包，不含源码。

**[下载最新版本](https://github.com/lubenwei-lian/neo-release/releases)**

---

## 这是什么

neo Android 版是一个运行在 Android 设备上的本地代理客户端，用于建立和管理代理连接。它基于开源项目 sing-box-for-android 构建，代理内核为 sing-box，改动集中在客户端功能与分流路由机制。

关于内核与客户端的分工，需要说明的是：

- **代理内核是开源项目**：所有代理协议、传输方式与加密能力都来自 sing-box 与 sing-box-for-android，neo 没有实现任何私有代理协议。
- **neo 做的是客户端**：不修改协议层，只做客户端功能与分流路由机制的实现和优化。

上游 sing-box 采用 GNU GPL v3 许可证，并明确要求未经许可不得使用其名称或暗示与其存在关联。neo 与 SagerNet、sing-box 官方没有任何关联。

## neo 做了哪些改动

### 多节点并发

普通代理客户端在同一时刻只使用一个节点，单节点的速度上限就是你的速度上限。neo 可以把同一订阅内协议相同、地区相同的节点组成一个并发组，由多个节点同时承担流量。

- **自动挑选参与节点**：按实测延迟排序，只保留最快的一批参与并发，慢节点不会被算进来，延迟记录过期的节点会自动移出。
- **拨号失败自动换成员**：某个节点对当前目标不可用时，这一条连接会自动改用组内其他节点重试，而不是直接失败。
- **游戏与语音的固定出口**：可以指定这些程序始终走同一个节点，避免多节点分摊带来的延迟抖动。其余流量不受影响，仍然享受并发叠加。

### 游戏分流

为 PUBG 等游戏注入 UDP 直连规则，让游戏对局的实时流量不经代理转发，用于降低延迟，避免代理转发造成的卡顿与丢包。

### 节点测速

使用独立的内核会话完成测速，不会中断或影响正在运行的 VPN 连接。可以同时测试多个节点，结果用于挑选并发组成员。

### 诊断日志

在设置中提供会话日志的查看与导出，用于定位连接问题：

- 日志按级别过滤，并剥离终端颜色转义码，默认可直接阅读。
- 单个日志文件达到行数上限时自动轮转，旧内容保留为上一份，不会丢弃最新日志。
- 超过保留期的会话日志自动清理。

### 界面

提供浅色、深色与跟随系统三种主题，支持动态取色与弹性转场。界面面板为玻璃质感，面板不透明度可以在 0 到 100 之间按自己的偏好调节。

### 工程化

应用内自带更新检查通道，并对安装包做完整性校验。

## 下载与安装

到 [Releases](https://github.com/lubenwei-lian/neo-release/releases) 页面下载最新的安装包：

| 文件 | 适用设备 |
|---|---|
| `neo-*-arm64-v8a.apk` | 主流 64 位 Android 手机 |

下载后直接在系统内安装即可。覆盖安装会保留已有的配置、订阅与设置。如果系统提示来自未知来源，需要在系统设置中允许该来源安装。

应用内的「设置 → 应用 → 检查更新」可以检查并获取新版本。
